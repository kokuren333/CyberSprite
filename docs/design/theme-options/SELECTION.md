# テーマの選定（SPEC §14.3.4 手順 2）

- 選定日: 2026-11-12
- 選定者: オーケストレーター（Claude Opus 5.5）。3 案の作成はデザイン担当（Claude Opus 5.5 / effort 中）
- **採用: 案 C「Solder Mask」**（緩和策つき）

## 判断

3 案とも §14.3.3 の制約（コントラスト比、色だけで状態を伝えない、キャンバス周囲の低彩度）を満たしている（`CONTRAST.md`。A 25/25、B 31/31、C 30/30）。そのうえで §14.3.4 の 3 つの観点で比べた。

| 観点 | A Silk | B Schematic | C Solder Mask |
|---|---|---|---|
| 白と水色の基板らしさ | 弱い（水色の 1px 線が白地で消えやすい） | 中（形で基板らしさを出すが、線は濃い銅色で水色は少ない） | **強い**（水色の配線とビア、チップ状のパネル） |
| ピクセルの鮮明さ | 良い | 良い | 良い（2px の配線、2 倍のツールアイコン） |
| 長時間使って疲れないこと | 最良 | 良い | 中（水色の面積が最も多い） |

デザイン担当の推奨は B だった。B は完成度が高く疲れにくいが、発注者の指定は「**白と水色を基調にした**基盤風」であり、B は水色が「選択中の印」に限られて、発注の第一印象から最も遠い。C は指定に最も直接に合い、疲労の懸念は面積の調整で下げられる。よって C を採り、M8 で次の緩和策を入れる。

1. 基板の下地を、より白に近づける（彩度を下げる）。
2. 非アクティブのパネルの見出し帯を白にし、水色の塗りはアクティブなパネルだけにする。
3. 本文 13px の設定を用意する（B の提案を取り込む）。
4. 動きを減らす設定で、配線を走る信号の演出を止める（§14.3.3。CSS には実装済み）。

発注者が B または A を望む場合は、トークン（CSS 変数）と見出しの描き方の差し替えで切り替えられる。3 案はこのディレクトリにそのまま残す。
