## 1. 画面ごとのメモ

### 01 起動直後の画面

- できること: ホームタブに、新規作成・開く・復元の入口、最近使ったファイルと最近のフォルダの一覧、配信されるお知らせの欄がある。上部に 8 個のメニュー（ファイル、編集、スプライト、レイヤー、フレーム、選択、表示、ヘルプ）。
- 対応する SPEC §7: §7.13（表示、UI）。CyberSprite の GUI では、ホームは「最近のプロジェクト」の一覧だけで足りる。お知らせ欄（ネットワーク接続）は §4.2 の規則 6 により持たない。

### 02 新規スプライトのダイアログ

- 選べる項目: 幅・高さ（ピクセル）、カラーモード 3 種（RGBA、グレースケール、インデックス）、背景 3 種（透明、白、黒）、詳細設定の開閉（ピクセル比など）。
- 対応する SPEC §7: §7.2。CyberSprite は常にインデックス（[D-03]）なので、カラーモードの選択はなく、代わりにパレットの選択を出す（§9.3 `new --palette`）。背景色の指定は `--background` に相当。

### 03 メイン編集画面（インデックスモード）

- 配置: 左にパレット（色の升目）と、その下に色の選択器（彩度・明度の面と色相の帯、16 進とインデックス番号の表示）。中央にキャンバスの編集領域。右端に縦 1 列のツールバー。上にツールごとの設定の帯（ブラシの形・大きさ、ピクセルパーフェクトの切り替えなど）。下にタイムライン（再生ボタン、レイヤーの行、フレームの列、表示・ロック・連続の切り替え）。最下部の状態表示に、スプライト名・大きさ、フレーム番号、表示倍率。浮動するプレビューの小窓を出せる。
- 対応する SPEC §7: §7.13、§14.2。

確認用のスプライトはすべて、確認用スクリプトで新規に作った（`_private/aseprite_ref/work/p*.lua`）。合成結果は、スクリプト内で 1 フレームを画像に描かせた値と、書き出したファイルを Python（Pillow）で読んだ値の両方で見た。

| P-01 | 3×3 の非対称なタイル（L 字）を作り、反転フラグ 8 通りでタイルマップに置いて描画した | 対角フラグは転置。対角＋X は「転置してから左右反転」、対角＋Y は「転置してから上下反転」と同じ形になった。8 通りすべて「対角 → X → Y」の順で説明できる | **合っていた** | §6.5.4 の「照合する」の注記を「確認済み」に直した |

## 4. 対応表（SPEC §7）に足した行、直した行

棚卸しで見つかった機能のうち、§7 の表に明示されていないものは、次の区分とする（I-005）。§7 の表への行の追加は、M8 の GUI 着手時にまとめて行う。

| 機能 | 区分 | 理由 |
|---|---|---|
| 選択範囲から新しいスプライトを作る | v1.x | 領域の取り出しは `transform_region` と書き出しの `crop` で代替できる |
| 文字の挿入（フォントで文字を描く） | 将来 | フォントの同梱とライセンスの確認が要る |
| マスク（選択範囲）ファイルの読み書き | 対象外 | 選択範囲は GUI の表示状態で、Op は領域を引数で受け取る（[D-30]） |
| コマンドの検索実行 | v1.x（GUI） | GUI の操作性。Op 一覧からの検索として作れる |
| 表示時間の一括設定、フレーム順の反転 | v1（Op の組み合わせ）／v1.x（専用 Op） | `set_frame_duration` を範囲に適用すれば足りる。反転は `move_frames` で可能 |
| シートのグリッド単位のトリム、グリッドでの分割 | v1.x | 書き出し側は `export_tileset` で代替できる |
| 指定の大きさまで縮小 | 対象外 | 非整数倍の縮小は原則 3 に反する |
| タグの繰り返しと入れ子を展開した書き出し | v1 | `export_animation` の `tag` 指定（§8.6.1）がこれに当たる |
