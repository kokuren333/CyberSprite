# 性能測定

## M6 組み込み変換（2026-11-12）

Windows、Python 3.12.10、NumPy 2.3.4、Pillow 13.0.0。再実行は `uv run python tools/benchmark_pipeline.py`。

| 入力・設定 | 測定範囲 | 3 回の時間 | 目標 |
|---|---|---|---|
| 1024×1024 PNG、元作品を4×4に並べ16倍、upscaled → 64×64 | 復号、グリッド、縮小、量子化、後始末、指標・関門、報告、stored 圧縮の全段階 PNG、最終 PNG、各 PNG の復号検証 | 805 / 1133 / 656 ms | 5000 ms 以内（全回達成） |

プロセスの起動と入力ファイルの作成は含めない。ディスクへの段階画像と報告の保存は含む。平均 865 ms、中央値 805 ms。無作為な写真・多数フレーム・全設定の上限時間を保証する測定ではない。

均等セルの純度と center 縮小は配列で計算し、色割当は異なる RGB ごとに整数 Oklab 距離を計算する。距離行列は4096色ずつ処理してメモリを制限する。孤立ピクセルは8方向の整数配列比較で数える。これらの経路は既存ベクタとコーパスの画素一致で検査する。
