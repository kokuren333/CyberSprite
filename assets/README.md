# assets/

自作の UI アセットの置き場所。**まだファイルはない。** 着手は M8（`docs/SPEC.md` §14.3）。

| ディレクトリ（予定） | 内容 |
|---|---|
| `ui/icons/` | 16×16 のピクセルアイコン。**原本は CyberSprite のプロジェクト（`*.csprite/`）**で、CLI でシートに書き出して GUI のビルドに組み込む |
| `ui/theme/` | テーマ「Circuit White」のデザイントークンと部品 |
| `ui/fonts/` | 見出し用のピクセルフォント（自作、または OFL-1.1 のもの。ライセンスを台帳に載せる） |
| `palettes/` | 同梱するパレットのプリセット（自作と、権利が明確なものだけ） |

## 規則

- すべて自作する。他製品のアイコン、スプライト、テーマ画像、配色表を取り込まない。
- デザインとビジュアルの判断は、必ず Opus 系が行う。
- パレットを一括で外部から取り込まない（`docs/SPEC.md` §2.4）。
