# 生成画像の較正入力 (d)

2026-11-12、組み込み `image_gen.imagegen` による16回の独立生成。13枚がドット絵風（うち三面図3枚）、3枚が非ピクセルの対照群である。既存のキャラクターや第三者の画像は入力していない。全プロンプト、生成日、元画像と保存画像のSHA-256、切り出し矩形は `manifest.json` にある。

モデルIDはツールが公開しなかったため `unknown`。出力ライセンスも出力規約の確認が未完なので `unknown` と明記する。Apache-2.0の自作コーパスと同じ権利状態だとは主張しない。

元画像の倍率・AA・圧縮状の構造を残すため、縮小・色の近似・JPEG再圧縮は行わない。外周を整数座標で切り出し、PNGへ可逆再圧縮した。三面図は横幅を保持し、上下だけを切り出した。非ピクセル対照群は中央64%の領域。PNG合計11,603,213 bytesであり、マニフェストを含めても12,000,000 bytes以内。

`apparent_step` はプロンプトの指定値で、検出の正解ではない。生成器は均一格子を保証しないため、正解画像や正しい格子数は付与しない。AUTOの寸法・候補指標・最終関門合否を測り、構図や作画品質の判定はオーケストレーターへ残す。
