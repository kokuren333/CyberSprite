# パイプライン較正（M6、版 1）

正本はこの文書。測定値は `calibration_metrics.json`、再実行は `uv run python tools/calibrate_pipeline.py`。
規範色表・整数パイプラインは共通で、JPEG と補間入力の作成だけに Pillow を使う。

| 分類 | 件数 | 完全一致 | grid_score 範囲 | fidelity 範囲 |
|---|---:|---:|---|---|
| (a) | 255 | 255/255 | 1000〜1000 | 0〜0 |
| (b) | 136 | 47/136 | 859〜1000 | 495〜466954543 |
| (c) | 34 | 6/34 | 415〜1000 | 33587〜34463395 |
| (e) | 12 | 0/12 | 53〜1000 | 19576〜11333584 |
| (f) | 34 | 0/34 | 730〜1000 | 0〜1784891 |

(a) は17作品の整数倍 ×2〜×16。全255件を auto で検出し RGBA で完全一致。
単色場には境界情報がないので fixed を指定する。今回の flat_field 作品には鳥と単独点があり検出できた。
(b) は ×4 を JPEG q60〜95（5刻み、subsampling=0）で圧縮。JPEG はアルファを保持しないため、透明作品の完全復元は期待できない。
(c) は5/2・7/2倍の bilinear 補間。正解の列数・行数を target で指定した。
(b)(c)(f) のパレットは正解の色。後始末は min_cluster=1、背景 keep、縮小 median。
(e) は12枚を4×4セルで測定し32色抽出。(f) は倍率4の入力へセル幅5・7を故意に指定。
(d) は M9 の生成バックエンド待ち。較正の完了を主張せず、到着後に版を上げて再測定する。

## しきい値の選択

grid_score の可能区間は [1001, 415]、採用 fail/warn は [415, 707]。
fidelity の可能区間は [466954543, -1]、採用 fail/warn は [466954543, 233477271]。
(e) と (f) 各95%拒否と (a)〜(c) 全合格を同時に満たす区間がない指標は、§11.9 の規則に従い正解格子の全合格を優先した。
fidelity は格子の正しさを測らず、疎な誤格子でも純度が高くなるため、これらの数値だけで非ドット画像や誤格子を95%拒否できるとは言えない。
ai/photo に較正値を適用。exact/upscaled の無損失 fidelity=0 と upscaled の厳密純度990/1000は、整数拡大の用途に限定して維持した。
