# examples/

自作のサンプルプロジェクトの置き場所。**まだファイルはない。** M10 で 3 点以上を作る（`docs/SPEC.md` §16.4）。

予定: キャラクターのアニメーション、タイルセット、生成画像からの取り込み例（来歴つき）。

- どのサンプルも、`validate` が通り、書き出しの自己検査が通った状態で置く（完了条件は `docs/SPEC.md` §13.7）。
- 絵は Opus 系が CyberSprite 自身で作る。他者の作品や他製品のサンプルを入れない。
- 生成画像を使うサンプルは、`source/manifest.json` に提供元、プロンプト、ライセンスを記録する。モデルの重みは入れない。
